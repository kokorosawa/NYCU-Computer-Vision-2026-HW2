\subsection{Key Findings}
\begin{enumerate}
    \item \textbf{The early DETR run (\texttt{xrob5wme}) converged very slowly:} at the latest epoch (21), AP is only 0.00003 (best AP=0.00039 at epoch 10).
    \item \textbf{After correcting the homework interpretation, Deformable DETR achieved much stronger results:} AP=0.2993 and AP50=0.5785 in run \texttt{kqscm42c}.
    \item \textbf{Within the successful run, learning is stable:} AP rises from 0.0329 (epoch 1) to 0.2993 (epoch 13).
\end{enumerate}
